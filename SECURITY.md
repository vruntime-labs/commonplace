# Security Policy

## Project status

Commonplace is currently in its planning and repository-foundation phase. The website and its content-processing systems are not yet deployed.

This policy will evolve as the project adds software, infrastructure, and public services.

## Scope

Security reports may concern:

- Repository configuration and access controls.
- GitHub Actions and other automation.
- Documentation or contribution processes that could expose users to harm.
- The future Commonplace website, APIs, and content submission pipeline.
- Security-sensitive guidance or resource entries published by the project.

For third-party tools and services listed by Commonplace, report vulnerabilities to their respective maintainers. Commonplace does not operate or control those projects.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue, discussion, or pull request.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If it is unavailable, contact the maintainers through a private GitHub communication channel and ask for a secure reporting route. Do not include exploit details in a public request.

A useful report may include:

- The affected component, file, workflow, or service.
- A concise description of the issue.
- Steps to reproduce, where safe.
- Potential impact and affected versions or configurations.
- Relevant logs, screenshots, or proof-of-concept material, with secrets and personal data removed.
- Suggested mitigations, if known.

Do not access, modify, or download data that does not belong to you. Avoid destructive testing, service disruption, persistence, or actions that could affect other users.

## Response and disclosure

Maintainers will review reports and make reasonable efforts to acknowledge and investigate them. Response and remediation times depend on severity, reproducibility, project capacity, and the availability of maintainers.

Please allow maintainers a reasonable opportunity to investigate and coordinate a fix before public disclosure. We will aim to communicate relevant remediation or mitigation information when appropriate.

No fixed response-time or remediation guarantee is made at this stage.

## Third-party resources

A resource being listed, described, or linked by Commonplace does not mean that it has been security-audited, endorsed, or guaranteed safe. Users should review the source, permissions, integrity, and risks of third-party software before installing or running it.
