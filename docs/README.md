# Documentation

This directory contains the planning and reference documents that guide Commonplace.

## Sections

- [Product](product/): product direction, scope, information architecture, and user journeys.
- [Content](content/): content types, metadata, provenance, and lifecycle requirements.
- [Brand](brand/): brand foundations and identity.
- [Design](design/): design principles, systems, and interface specifications.
- [Architecture](architecture/): technical architecture and engineering decisions.
- [Governance](governance/): community, editorial, and contribution governance.
- [Roadmap](roadmap/): milestones and implementation planning.

## Product documents

- [Product strategy](product/product-strategy.md): approved product direction and MVP scope.
- [Information architecture](product/information-architecture.md): approved sitemap, navigation, content areas, and shared page patterns.
- [User journeys](product/user-journeys.md): approved MVP journeys, success criteria, and contribution flows.

## Content documents

- [Content model](content/content-model.md): approved content types, provenance, metadata, relationships, and lifecycle states.

## Governance documents

- [Editorial policy](governance/editorial-policy.md): standards for original Commonplace publishing, community contributions, external resources, and editorial review.
- [Contribution guidelines](governance/contribution-guidelines.md): contribution routes, content expectations, review process, attribution, and safety.

## Document status

Documents should state their status clearly:

- **Draft:** work in progress; not approved.
- **Under review:** awaiting feedback or a decision.
- **Approved:** accepted as the current project direction.
- **Superseded:** replaced by a newer document or decision.
- **Archived:** retained for historical reference.

A document being committed to this repository does not automatically mean its proposals are approved.
