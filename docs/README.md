# Documentation

This directory contains the planning and reference documents that guide Commonplace.

## Sections

- [Product](product/): product direction, scope, and decisions.
- [Brand](brand/): brand foundations and identity.
- [Design](design/): design principles, system, and interface specifications.
- [Architecture](architecture/): technical architecture and engineering decisions.
- [Governance](governance/): community, editorial, and project governance.
- [Roadmap](roadmap/): milestones and implementation planning.

## Document status

Documents should state their status clearly:

- **Draft:** work in progress; not approved.
- **Under review:** awaiting feedback or a decision.
- **Approved:** accepted as the current project direction.
- **Superseded:** replaced by a newer document or decision.
- **Archived:** retained for historical reference.

A document being committed to this repository does not automatically mean its proposals are approved.
